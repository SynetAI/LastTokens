# apim-1 v7.2 主题重设计说明（机甲 / 赛博）

对应文件：`packages/pkg-10/client.js`（完整单文件，`styles.insert()` 内 CSS + React 渲染）。
本版本只重做两个主题层，组件基类（`.dsm-panel/.dsm-fab/.dsm-stat…`）与 JS 结构契约不变。

## 2. 机甲 Mecha：钛金装甲 · 能量核心

- **面板**：枪灰装甲板（竖向钢板渐变 + 双向细丝刷纹），两角 18px 切角
  `clip-path`，内框亮钢线，四角钢制螺栓（亮心+灰环+暗座），深投影 + 橙色外晕。
- **头部**：顶部 4px 橙黑警示条纹，标题 `⚙ API 装甲面板` 琥珀渐变 + 2.5px 字距。
- **布局**：统计卡改为**纵向装甲模块列表**（每行：左能量条 + 切角图标板 +
  标签/副文 + 右对齐亮琥珀数值 + 右侧 45° 散热纹），悬停右移 + 橙色辉光。
- **特效**：面板左侧 2px **能量导管**，光脉冲自上而下循环流动（`dsm-mecha-flow`）；
  **能量槽**（输入/缓存/输出三段琥珀渐变 + 刻度线 + 扫光 `dsm-mecha-sweep`）。
- **悬浮球**：涡轮核心（径向金属高光 + 深棕包边），外围分段装甲环缓慢旋转
  （`dsm-mecha-breathe`），深棕数字白描边。
- 图表卡 / 记录行 / 按钮 / 页脚：直角 + 细警示条纹 + 橙色描边，按钮 7px 切角。

## 3. 赛博 Cyber：霓虹终端 · 数据流

- **面板**：10px 圆角深空底，`@property --dsmAngle` 驱动**青→紫→品红三色流光边框**
  环绕旋转（4s），无 glitch 抖动。
- **头部**：`> API_DASHBOARD` 等宽字体终端标题 + 光标闪烁，底部**透视数据地板网格**。
- **布局**：统计卡由旧 4 列（352px 内每卡仅 ~80px）改为 **2×2 HUD 磁贴**：
  右上切角、顶部青色高光线、等宽数值 + 品红/绿状态色，副文恢复显示。
- **特效**：背景点阵 + 细网格（顶部渐隐遮罩）；**扫描光束**放慢至 5s；
  **能量槽**三段青/紫/品红渐变 + 青色扫光；余额数字柔光呼吸（`dsm-num-pulse`）。
- **悬浮球**：圆形霓虹核心（弃用六边形——不再裁掉并发徽标），
  外围**青/紫/品红三色数据环**旋转 + 内核脉冲光晕（`dsm-core-breathe/dsm-core-pulse`）。
- 记录行 / 按钮：6px 切角、等宽字体、青色 hover 辉光；边框全部改实线（弃虚线）。

## 4. 行为变更（JS）

- 赛博主题同样渲染能量槽（`tokenbar` 条件由 `gilded` 扩为 `gilded || cyber`）。
- 主题选择写入 `localStorage['dsm-theme']`，刷新后保持（读取时白名单校验）。
- 面板头部三个图标按钮补 `aria-label`。
- 新增全局 `:focus-visible` 焦点环（`2px solid var(--dsmT1)`）与
  `prefers-reduced-motion` 动画降级。
